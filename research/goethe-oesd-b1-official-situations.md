# Goethe-/ÖSD-Zertifikat B1: situations in the official sets (do-not-reuse list)

**Stand: 24.10.2026** · paraphrased from the official practice sets, read on 2026-10-24 (sources in `goethe-oesd-b1.md` §7 and §8).
The official texts are copyright. This file lists only the **situation and the detail each task tests**, in our words, so the
generator can avoid them. Keep the official wording for any overlap check in `.unit-cache/official-goethe-b1/` (gitignored), never
in the repo.

**Which sets these are.** Goethe and ÖSD publish the **same** adult sets under both brands:

- **[MS] Modellsatz Erwachsene.** Goethe edition © 2013/2015, and ÖSD Band 1 (2026) §5.1 plus the ÖSD homepage Modellsatz. Same
  items and the same audio recording. ÖSD's print only adapts spelling to the writer's country (Austrian *Kassa*, Swiss *ss* and «»).
- **[ÜS] Übungssatz Erwachsene.** Goethe edition © Goethe·ÖSD 2016, and ÖSD Band 1 (2026) §6.1. Same items.
- **[MS-J] / [ÜS-J] Modellsatz / Übungssatz Jugendliche** (ÖSD Band 1 §5.2, §6.2). Same format in *du*. Read only for situations;
  some lines are partial (marked).

Region tags: **D** / **A** / **CH** = the country the text or speaker is placed in by explicit cues (place, web domain, phone prefix,
glossed regional word). **–** = no regional cue. Speaker *accents* are not tagged here (see `goethe-oesd-b1.md` §8.4: not verified by ear).
