# Goethe-Zertifikat A2 (Erwachsene): situations in the official sets (do-not-reuse list)

**Stand: 24.10.2026** · paraphrased from the two official sets that are public:

- **ÜS** = *Goethe-Zertifikat A2 Übungssatz 01 Erwachsene* (© 2020, 1st ed. Jan 2021, PDF version Vs0.6_050526) [G3 in `goethe-a2.md`]
- **MS** = *Goethe-Zertifikat A2 Modellsatz Erwachsene* (© 2016) [G3b]. The accessible online Modellsatz on bfu.goethe.de [G2] is the **same set** (same texts, items and audio).

The official texts are copyright. This file lists only the **situation and the detail each task tests**, in our words, so the
generator can avoid them. Never put official wording into a prompt or a draft. Page cites are the printed page ("S.") of each PDF.

Both sets are widely paraphrased by competitors (TestGerman's Goethe A2 mocks retell the MS article and email almost point by
point, see `goethe-a2.md` §11.4). Avoiding these situations also keeps us clear of those clones.

## Answer-key distribution (from the Lösungen sheets, ÜS S. 32, MS S. 32)

No letters or items are reproduced here, only the patterns the generator should imitate.

| | ÜS | MS |
|---|---|---|
| a/b/c spread over the 25 three-option items (Lesen T1–3, Hören T1, T3) | a 3 · b 14 · c 8 | a 6 · b 9 · c 10 |
| Longest run of one letter inside a Teil | 3 (Lesen T2, plus 4 of 5 the same letter) | 3 (Lesen T1) |
| Lesen T2: how often c ("andere Halle / anderer Stock") is right | 1 of 5 | 2 of 5 |
| Lesen T4: position of the X item | 4th of 5 | 3rd of 5 |
| Lesen T4: ads used | example 1 + 4 answers, **1 ad left over** | same |
| Hören T2: picture use | example 1 + 5 answers, **3 distractors**, each distractor is an activity mentioned as planned/rejected | same |
| Hören T4: Ja / Nein (example is Ja in both) | 3 Ja · 2 Nein, max run 2 | 2 Ja · 3 Nein, max run 2 |
| Hören T1: last item | answer a in both sets | |

**Takeaways for the generator:**

- Goethe does **not** balance letters per set. Don't force an even a/b/c spread, but avoid answer patterns that a candidate could game (e.g. every Teil the same letter).
- Every Teil 1 (Hören) clip mentions all three options. The wrong ones are said, then changed or ruled out.
- In Hören Teil 2 the slots run in dialogue order and every distractor picture is something the speakers mention but don't do.
- In Hören Teil 3 the dialogue mentions all three pictured things; the decision comes late.
- Lesen Teil 4: the "no match" person has an ad that almost fits (wrong product, wrong service).
